01 — Overview
Improvement proposal

CRM Follow-Up Status Enhancement

Automatic intelligence. Human control when needed.

The Follow-Up column in the Leads list is updated automatically from recorded activity. That automation is valuable, but it does not always reflect what actually happened with the client. This proposal keeps the automation and adds one thing: authorized users can correct the Follow-Up status directly from the Leads list, and that correction is protected from being silently overwritten.

Scope
Follow-Up column only
Approach
Automatic by default + manual override
Who can edit

03 — Proposal

Automatic by default. Manual when needed.

Keep the existing Follow-Up automation. Add a manual override for the cases where the automation gets it wrong.

Current

Automated only

  • ·Status is set by the system from recorded activity
  • ·Interactions outside the CRM are not reflected
  • ·Incorrect values cannot easily be corrected
  • ·Team verifies rows manually
Recommended Proposed

Automatic + Manual Override

  • ✓Automation continues exactly as today when it detects activity correctly
  • ✓Authorized users correct an inaccurate status directly from the Leads list
  • ✓Each value shows whether it is Automatic or a Manual Override, with who and when
  • ✓Manual corrections are protected from being overwritten by the next automatic update
The key rule

A manual correction is not immediately overwritten by the next automated update. A manually corrected status remains protected until one of two things happens:

  1. The authorized user changes it again, or
  2. A clearly new client interaction occurs, according to the agreed CRM logic.

06 — Override

Manual override experience

Four actions, all inside the Leads list. No separate screen, no form to fill.

Step 1Review
Step 2Identify incorrect status
Step 3Edit
Step 4Save

What the user sees

The advisor opens the Follow-Up value on the row, picks the status that matches the real interaction, and saves. The column immediately shows the new value with a small Manual Override line: who changed it and when.

  • The dropdown offers the six agreed statuses and nothing else.
  • Only authorized users see the edit control. Everyone else sees the same read-only value.
  • Every override is visible on the row itself, so managers can tell at a glance which values were corrected by a person.
  • The override is only needed when the automated status does not represent the actual client interaction.

07 — Impact

Why this matters

The Follow-Up column is where the team decides who to call next. When it is right, everything downstream is faster.

01

Fewer missed follow-ups

A lead marked as handled is actually handled. Leads that still need attention stay visible until someone acts.

02

Less duplicate outreach

Clients already reached by phone or in person are not contacted a second time because the system did not know.

03

Faster lead review

Managers and advisors can trust the list at a glance instead of opening each record to confirm the real state.

04

More reliable CRM data

Corrections are recorded with who and when, so reports built on Follow-Up status reflect what happened.

08 — Scope

What stays the same

This proposal is deliberately narrow. It changes how one column behaves and nothing else.

Only this changes Follow-Up column behavior

Automatic status remains. A manual override is added for authorized users, with a visible source indicator and protection from automatic overwrite.

  • =Lead assignment
  • =SLA / response timing
  • =Lead status
  • =Pipeline

  • =Communication history

  • =Warm / Cold scoring
