Follow-up Status: accurate by default, correctable when needed

The Follow-up column updates itself from system activity, but it does not always match what actually happened with the customer. This proposal keeps the automation and adds a simple manual correction for authorized users.

Prepared for: CRM / IT team Area: CRM › Leads › Follow-up column Date: 5 September 2026 Type: Improvement suggestion
1

Problem

The automated Follow-up status is not always right.

The Follow-up column is currently fully automated. Its value changes based on the follow-up and contact activity the system records. In practice the automated status often lags behind, or misses, the real conversation with the customer.

  • A follow-up has already been completed, but the status does not update.
  • The customer was reached through another channel (phone, walk-in, personal text), and the system did not see it.
  • The status shown is out of date compared to the latest interaction.
  • When the status is wrong, users have limited ability to correct it.
Result today

The Leads list cannot be fully relied on when deciding which customers still need a follow-up. Advisors end up double-checking notes and history to confirm what the column should already tell them.

2

Why it matters

Follow-up is where inquiries turn into bookings.

Leads arrive from two web apps plus phone and text, with a one-hour response target. The Follow-up column is the one place the team looks to see who still needs attention. When it is inaccurate, three things happen:

  • Customers get missed. A lead that shows as followed up may never have been reached.
  • Customers get contacted twice. A lead that shows as needing follow-up may already have been handled by phone.
  • Reviews take longer. Managers cannot trust the list at a glance and must verify each row.

A small correction feature restores trust in the column without changing how leads flow through the CRM.

3

Suggested improvement

Two possible ways to manage the Follow-up status. One is recommended.

Option 1

Manual update

Authorized users set the Follow-up status themselves, based on the actual interaction with the customer.

Needs Follow-up ▾
Needs Follow-up Followed Up Contacted No Response Waiting for Customer Completed

Simple and always accurate to what the advisor knows, but the team loses the time-saving automation.

Option 2 · Recommended

Automatic + manual correction

Keep the existing automatic updates. When the automated status is wrong, an authorized user corrects it manually.

Followed Up ▾ Manually updated

The CRM stays automated where it works, and the team has control where it does not.

Recommended approach: automatic by default, manual override

The system keeps updating the Follow-up status automatically from customer contact and activity. If that status is incorrect, an authorized user can change it directly in the Leads list.

Important rule

A manual correction must not be immediately overwritten by the next automated update. Once a user has corrected the status, the system should keep that value until the user changes it again, or until a clearly new customer interaction occurs.

Where helpful, the column can show a small indicator of how the value was set, for example Followed Up · Manually updated or Needs Follow-up · Automatic. This keeps the column transparent without adding clutter.
